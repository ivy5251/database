## Heptabase 合併說明

> 2026/9/28 將 `from-heptabase/醫學`（916 份 Heptabase 匯出卡片）中與急診相關的內容併入本資料夾。

### 做了什麼
- **篩選**：只收急診相關卡片；日記、心情紀錄、面試題、Heptabase 教學卡、基礎生理（腎臟生理、Guyton）、慢性病／門診主題、ClinicalKey 網頁殘骸未收。
- **合併原則**：Heptabase 卡片很零碎，依主題合併；已有 Notion 版本的主題，把 Heptabase **有、Notion 沒有**的內容補進同一份筆記，內容重複的不重列（Source 行會註明）；Notion 沒有的主題才新建檔（上方目錄標 🆕）。
- **格式統一**：所有 01–11 筆記標題改英文、`> Source:`／`> Related:`、五段式（含新增的 **Disposition**）；空段落只寫「（待補）」。
- **不補外部資料**：只搬原筆記與原圖片裡有的內容，沒有自行補充醫學知識，預留之後整合 Tintinalli。
- **標記方式**
  - `🖼️ 圖片轉錄`：從卡片圖片（表格、流程圖、投影片翻拍）轉成的文字
  - `（Heptabase）`：同一份筆記中來自 Heptabase 的段落
  - `⚠️ 原文如此，待查證`：原文疑似錯字、數值不一致或兩個來源互相矛盾，**未擅自修改**
- **圖片**：需要看圖的（EKG、CT、超音波、臨床照片）複製到各資料夾 `assets/` 並嵌入；純文字圖改成轉錄。
- **刪除重複**：Heptabase 的「🔎經驗型抗生素」「兒童抗生素使用」「Constrictive Pericarditis」與 Notion 版相同，未重複匯入；手術傷口分級只保留在 [傷口處理](08_外傷與外科/傷口處理.md)。

### ⚠️ Heptabase 合併時標出、需要你確認的地方
| 檔案 | 問題 |
|---|---|
| 供氧裝置 | NRM 的 FiO2 三個來源數字不一致；Simple mask 流量「太高」vs「太小」會吸入 CO2 |
| 死亡與腦死判定 | 「GCS <5（E1M3V1）」但 E1M3V1 = 5 |
| Tachycardia與QT延長 | TdP 診斷：Notion 寫 PVC，Heptabase 寫 PVT |
| Heart_Failure | SGLT-2i 底下寫「選擇：Enalapril」 |
| Shock | 投影片「外種內腫」疑似錯字 |
| Meningitis | Viral meningitis 寫 Enterococcus（疑為 enterovirus） |
| 中風Stroke | Posterior stroke 5D 第五個 D：Dyspraxia vs Dystaxia |
| 胸水與膿胸 | CPPE 的 LDH 切點 >1000 vs >600（且單位 mg/dL） |
| 低血鈉與SIADH | N/V 屬於急性還是慢性低血鈉，兩版本不同 |
| Trauma總論 | Flail chest：「ORIF 很少需要」vs「early surgery」 |
| IICP | 「CCP >60」疑為 CPP |
| 高血鈉 | 「洗 CRT」疑為 CRRT |
