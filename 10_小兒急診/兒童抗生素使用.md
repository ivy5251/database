## Medications
### 一、Sepsis／TSS／Febrile neutropenia

1. **Community-acquired sepsis（不含[腦膜炎](../04_休克與感染/Meningitis.md)）**
   - 👶 **≤2 個月**：Ampicillin + Gentamicin；懷疑 MRSA ＋Vancomycin
   - 👦 **>2 個月**：Cefotaxime 或 Ceftriaxone；懷疑 MRSA ＋Vancomycin
   - 敗血性[休克](../04_休克與感染/Shock.md)：Cefotaxime + Gentamicin + Vancomycin
2. **Nosocomial sepsis**：Piperacillin-tazobactam；有 CVC ＋Vancomycin；敗血性休克 ＋Gentamicin
3. **Toxic shock syndrome**：Cefotaxime + Clindamycin + Vancomycin
   - Group A Strep：Penicillin + Clindamycin + IVIG
   - S. aureus：Oxacillin + Clindamycin + Vancomycin + IVIG
4. **[Febrile neutropenia](../04_休克與感染/Febrile_Neutropenia.md)（>1 個月）**：Tazocin、Cefepime、或 Ceftazidime + Gentamicin；病危 ＋Vancomycin

### 二、Pneumonia

1. **Severe CAP <5 歲**
   - 首選 Cefotaxime
   - 懷疑 MRSA：Ceftaroline，或 Cefotaxime + Vancomycin/Linezolid
   - 生命危急：＋Clindamycin ± Azithromycin/Clarithromycin
2. **Severe CAP >5 歲**
   - 首選 Cefotaxime ± Azithromycin/Clarithromycin
   - 懷疑 MRSA 或危重：Ceftaroline + Clindamycin，或 Cefotaxime + Vancomycin/Linezolid + Clindamycin
   - [膿胸](../03_呼吸與酸鹼/胸水與膿胸.md)：Cefotaxime + Vancomycin ± drainage，或 Ceftaroline
3. **Nosocomial／VAP**
   - <5 天：Cefotaxime
   - ≥5 天：Tazocin／Meropenem／Cefepime ± Gentamicin
   - 懷疑 MRSA：＋Vancomycin 或 Ceftaroline

### 三、腹腔內感染（含 NEC）

- Option 1：Ampicillin + Gentamicin + Metronidazole，或 Ceftriaxone + Metronidazole
- Option 2：Tazocin、Meropenem 或 Imipenem

### 四、皮膚／軟組織／骨

1. **嚴重[蜂窩性組織炎](../04_休克與感染/軟組織感染.md)／骨髓炎**
   - <5 歲：Cefotaxime；懷疑 MRSA ＋Vancomycin 或改 Ceftaroline
   - ≥5 歲：Oxacillin；懷疑 MRSA ＋Vancomycin
2. **懷疑 necrotizing fasciitis**
   - Cefotaxime + Vancomycin + Clindamycin
   - 或 Ceftaroline + Clindamycin
   - 或 Ceftazidime（Cefepime）+ Vancomycin（Ceftaroline）+ Clindamycin
   - 外傷接種相關：Meropenem + Vancomycin + Clindamycin
3. 骨折預防：Cefazolin；有感染：Tazocin

> 註：原筆記「5 天」「5 歲」處推測為 ≥5，已補上符號。
