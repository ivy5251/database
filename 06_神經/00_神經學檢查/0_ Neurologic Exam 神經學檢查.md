# Nystagmus

> [!pearl] 看中間就會眼震 -> spontaneous nystagmus
  - Nystagmus 的原因：中樞把歪掉的眼睛調回來！

| 眼震類型                                       | 臨床特徵                                                                                                                                                                                            | 常見病因                                                                                                                                                                                      |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 周邊性自發性眼震（Peripheral spontaneous nystagmus） | • 急跳型眼震（Jerk nystagmus）<br>• Mixed torsional-horizontal nystagmus<br>• 常伴隨眩暈或嘔吐<br>• 可被視覺固視（Visual fixation）部分抑制                                                                                | • 前庭神經炎（Vestibular neuritis）<br>• 迷路炎（Labyrinthitis）<br>• 梅尼爾氏症（Ménière disease）<br>• 偏頭痛（Migraine）<br>• 良性陣發性姿勢性眩暈（BPPV）                                                                 |
| 中樞性自發性眼震（Central spontaneous nystagmus）    | • 急跳型或鐘擺型眼震（Jerk or pendular nystagmus）<br>• 相對較少伴隨眩暈（Vertigo）<br>• 通常無法被視覺固視（Visual fixation）抑制                                                                                                | • [Stroke](../01_中風/中風Stroke.md)：腦幹病灶（如 Wallenberg syndrome）、小腦病灶<br>• Parinaud syndrome<br>• 韋尼克腦病變（Wernicke encephalopathy）<br>• 多發性硬化症<br>• 藥物或物質中毒                                             |
| 凝視誘發性眼震（Gaze-evoked nystagmus）             | • Jerk nystagmus<br>• 維持眼球偏離正中位置（Eccentric eye position）時產生<br>• 為最常見的眼震類型<br>• 可**藉由眼球運動檢查，要求病人向水平方向極端位置凝視而誘發**<br>• 眼震快相朝向偏心凝視方向（**Fast phase toward eccentric gaze**）<br>• 眼震持續超過 20 秒（原文描述） | • 中風（Stroke）：中腦病灶（Midbrain lesion，純垂直性眼震）、橋腦延髓病灶（Pontomedullary lesion，純水平性眼震）<br>• 藥物或物質中毒（Intoxication）：鎮靜劑（Sedatives）、抗癲癇藥物（Anticonvulsants）、酒精（Alcohol）<br>• 重症肌無力（Myasthenia gravis） |
