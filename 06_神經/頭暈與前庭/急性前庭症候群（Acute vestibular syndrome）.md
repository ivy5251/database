
- 急性發作、持續**數天、不間斷**
- 頭動會加重，但**不只在動作當下才有**
- 最重要鑑別：**前庭神經炎 vs 後循環[中風](../01_中風/中風Stroke.md)**（小腦、腦幹）

| 前庭症候群              | 常見良性（非致命性）病因                 | 重要危險（可能危及生命）的鑑別診斷                                 | 其他重要但較少見的病因                                                                                                                |
| ------------------ | ---------------------------- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| AVS（約 30%） 急性前庭症候群 | • 前庭神經炎（Vestibular neuritis） | • 後循環缺血性中風（Posterior circulation ischemic stroke） | • 後顱窩出血（Posterior fossa hemorrhage）<br>• Wernicke syndrome<br>• Labyrinthitis<br>• 多發性硬化症（Multiple sclerosis）<br>• 藥物或毒物中毒 |
|                    |                              |                                                   |                                                                                                                            |
## HINTS
-  只適用於「==急性、持續性、*有眼震*==」的病人
- 做法
	- **H**ead **i**mpulse
		 ![Head impulse](assets/Head_impulse_test.jpg)
	- **N**ystagmus
	- **T**est of **S**kew
- 受過訓練的醫師用 HINTS 可比一般[神經學檢查](../00_神經學檢查/0_%20Neurologic%20Exam%20神經學檢查.md)更早抓出中樞病灶
- **HINTS 中樞型或有central red flag → 優先 MRI**（CT 不足以排除）
