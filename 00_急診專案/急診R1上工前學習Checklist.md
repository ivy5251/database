# 🚑 急診 R1 上工前學習 Checklist（2026/7/7～8月底）

> 合併自 Notion 兩份重複頁面：「急診 R1 上工前學習 Checklist（2026/7/7～8月底）」與「急診R1上工前學習計畫checklist」。已勾選的進度保留。

**目標**：九月成為不慌張的急診 R1。上工前建立 POCUS、ECG、影像判讀與急症初步處置的基礎，procedure 步驟熟到能默背；內科疾病本身已有 PGY2 基礎，不重複投資。

> 使用方式：每完成一項就打勾。北歐旅行（8月中，16 天）期間只做「維持模式」，不排新進度。

## 第 1～2 週（7/7～7/19）｜POCUS ＋ 氣道與 RSI

### POCUS（主資源：pocus101.com）
- [x] 超音波物理與旋鈕基礎：探頭選擇（linear／curvilinear／phased array）、depth、gain、TGC
- [ ] 肺部超音波：lung sliding（seashore sign 的「顆粒在移動」感）、A-lines vs B-lines
- [ ] 肺部超音波：氣胸判讀——lung sliding 消失、lung point、M-mode 對照 barcode sign
- [ ] eFAST：RUQ（Morison's pouch）、LUQ、pelvis、subxiphoid 四個 view 的探頭位置與判讀
- [ ] 心臟四切面：PLAX、PSAX、A4C、subxiphoid 的取像手法
- [ ] 心臟判讀：目測 EF（好／中／差）、pericardial effusion 與 tamponade 徵象、RV strain（D-sign）
- [ ] IVC 評估：量測位置、直徑與呼吸變異度、volume status 的解讀限制
- [ ] RUSH protocol：把 pump–tank–pipes 整合成休克鑑別流程
- [ ] 實作：在內科病房徵得同意，累積至少 10 次肺部＋IVC 掃描練習

### 氣道與 RSI
- [ ] RSI 7 Ps 流程默背：Preparation → Preoxygenation → Pretreatment → Paralysis with induction → Positioning → Placement with proof → Post-intubation management
- [ ] 困難氣道評估：LEMON（Look, Evaluate 3-3-2, Mallampati, Obstruction, Neck mobility）
- [ ] 誘導藥物：etomidate（劑量、血行動力學穩定、adrenal suppression 爭議）
- [ ] 誘導藥物：ketamine（劑量、升壓、支氣管擴張；適應症：氣喘／休克、禁忌與迷思）
- [ ] 誘導藥物：propofol（劑量、低血壓風險、適合 status epilepticus）
- [ ] 肌鬆劑：succinylcholine——劑量與禁忌症（高血鉀、燒燙傷 >48hr、crush injury、神經肌肉疾病、denervation、惡性高熱病史）
- [ ] 肌鬆劑：rocuronium——劑量（1.2 mg/kg RSI dose）、作用時間、sugammadex 反轉
- [ ] MG 病人的 RSI 特殊考量：對 succinylcholine 有阻抗性、對非去極化肌鬆劑（rocuronium）極度敏感須大幅減量（連結 UpToDate MG 禁忌用藥筆記）
- [ ] 插管確認：EtCO2、雙側呼吸音、CXR 位置判讀
- [ ] Post-intubation：鎮靜止痛安排、初始呼吸器設定（TV 6–8 ml/kg IBW、RR、FiO2、PEEP）
- [ ] Post-intubation hypotension 的鑑別與處理（DOPES、sedation、tension pneumothorax）
- [ ] 備援計畫：BVM＋airway adjuncts、LMA／supraglottic airway、cricothyrotomy 的決策點
- [ ] Tracheostomy 急症複習：tract 成熟時間（約 7 天）、脫位處理原則、trach 病人喘的鑑別（痰痂、脫位、出血／TIF）

## 第 3～4 週（7/20～8/2）｜ECG ＋ 急症初步處置

### ECG（資源：LITFL ECG Library；進階：Amal Mattu ECG Weekly）
- [ ] 系統性判讀順序建立：rate → rhythm → axis → intervals → ST/T → 比對舊圖
- [ ] STEMI 標準判準與各導程對應血管
- [ ] STEMI equivalents：Wellens syndrome（Type A/B）
- [ ] STEMI equivalents：De Winter T waves
- [ ] STEMI equivalents：posterior MI（V1–V3 ST depression → 加做 V7–V9）
- [ ] STEMI equivalents：aVR ST elevation＋widespread depression（LMCA／三支病變 vs 瀰漫性缺氧）
- [ ] 高血鉀 ECG 進程：peaked T → PR 延長 → QRS 變寬 → sine wave（連結筆記：bradycardia 先想酸中毒與 hyperK）
- [ ] 低血鉀、高低血鈣的 ECG 變化
- [ ] Long QT 與 Torsades de Pointes：常見致 QT 延長藥物、辨識與處置（MgSO4）
- [x] Brugada pattern（Type 1）辨識
- [ ] WPW：delta wave 辨識、WPW＋AF 為何禁用 AV node blockers、處置（procainamide／電擊）
- [ ] Bradycardia approach：一張流程圖（不穩定的處置階梯 atropine → pacing → epi/dopamine；含藥物中毒考量）
- [ ] Tachycardia approach：narrow vs wide、regular vs irregular 的決策樹；寬 QRS 心搏過速一律先當 VT 處理
- [ ] 每天 3–5 張 ECG 判讀練習（LITFL Top 100 或 ECG Weekly）

### 急症初步處置（每天一個主訴，整理成「前十分鐘卡片」）
- [ ] Chest pain：致命五診斷（ACS、PE、aortic dissection、tension pneumothorax、esophageal rupture）的排除流程與初步檢查順序
- [ ] Dyspnea：approach＋POCUS 整合（BLUE protocol 概念）
- [ ] Shock：四大分類（hypovolemic／cardiogenic／obstructive／distributive）＋RUSH 對應
- [ ] Anaphylaxis：診斷判準、epinephrine 劑量與給法（0.3–0.5 mg IM 大腿外側）、biphasic reaction 觀察（讀本：台灣急診醫學會 EJournal 該篇）
- [ ] Altered mental status：AEIOU-TIPS 鑑別＋立即要排除的（血糖！、CO2、CT）
- [ ] GI bleeding：初步復甦、risk stratification（Glasgow-Blatchford）、massive transfusion 啟動時機、何時緊急內視鏡、藥物（PPI、octreotide、抗生素 for 肝硬化）
- [ ] Sepsis：辨識（qSOFA/SIRS）、1-hour bundle、lactate、抗生素選擇原則
- [ ] Status epilepticus：BZD 劑量 → 二線抗癲癇藥流程
- [ ] Hyperkalemia 處置順序：calcium → insulin/glucose → 排鉀（連結 ECG 章節）
- [ ] DKA/HHS：初步處置順序（fluid → K → insulin）、鉀離子補充時機與常見陷阱
- [ ] 常見 toxidromes：opioid、sympathomimetic、anticholinergic、cholinergic、sedative 的辨識與解毒劑
- [ ] 常用解毒劑清單：naloxone、flumazenil（禁忌）、NAC、fomepizole、hydroxocobalamin
- [ ] ACLS algorithm 複習：cardiac arrest（VF/pVT、asystole/PEA）
- [ ] OHCA／ROSC 後照護：目標血壓、體溫管理、找原因
- [ ] Hs & Ts（5H5T）默背並能對應處置

## 第 5 週（8/3～北歐出發前）｜影像判讀 ＋ Procedures

### 影像判讀（題庫：Radiopaedia case library）
- [ ] CXR 系統性判讀法（ABCDE）建立成固定流程
- [ ] CXR：氣胸（含 deep sulcus sign）、tension pneumothorax
- [ ] CXR：肺水腫分期、肺水腫 vs 肺炎 vs ARDS 的圖形區分、pleural effusion、consolidation
- [ ] CXR：free air under diaphragm、縱膈腔變寬（dissection 線索）
- [ ] CXR：管路位置確認（ETT、NG、CVC）
- [ ] Head CT：EDH vs SDH vs SAH vs ICH 的型態辨識與臨床對應
- [ ] Head CT：early ischemic signs、midline shift、herniation 徵象
- [ ] Abdominal CT：free air、appendicitis、diverticulitis
- [ ] Abdominal CT：AAA／rupture、腸阻塞（transition point）、mesenteric ischemia 線索
- [ ] Radiopaedia 刷 case：每天 5 個；總目標 CXR ×20、Head CT ×15、Abd CT ×15

### Procedures（學法：NEJM Videos／EM:RAP HD → 寫步驟 checklist → 閉眼心智演練到默背）
- [ ] Chest tube：適應症、safe triangle 定位、器械清單
- [ ] Chest tube：逐步驟 checklist（麻醉→切開→鈍剝→手指確認→置管→固定→接水下引流→CXR 確認）、引流系統判讀
- [ ] Finger thoracostomy：tension pneumothorax／traumatic arrest 的緊急減壓
- [ ] Needle decompression：位置更新（第 4–5 肋間 anterior axillary line）與限制
- [ ] Central line（IJ 為主）：超音波導引步驟、Seldinger technique、併發症
- [ ] Lumbar puncture：定位、姿勢、opening pressure、禁忌症（何時先 CT）
- [ ] 各 procedure 心智演練：閉眼能完整默背步驟各 3 次以上

## 臨床珍珠（持續累積）
- Tracheostomy 病人喘：先問「什麼時候切的」——術後 <7 天 tract 未成熟，脫位盲插易成 false passage，寧可考慮從口插管
- Bradycardia：先想酸中毒與高血鉀
- 氣胸 echo：lung sliding 是「顆粒在移動」的感覺（seashore sign），M-mode 消失變 barcode sign
- MG 禁忌用藥清單（UpToDate）＋肌鬆劑劑量調整
