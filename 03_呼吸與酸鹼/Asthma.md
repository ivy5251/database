## Key Points
- 病因：氣管過度敏感 → 接觸過敏原 → **平滑肌收縮**
- 臨床表現：**wheeze、SOB、cough、chest tightness**
- 小孩懷疑 asthma 可特別問
  - PH：allergic rhinitis、eczema
  - FH：asthma、allergy、atopic dermatitis

### 急性發作的 PE
- 呼吸及心跳急促、咳嗽、**wheezing**、呼氣時間延長
- 有時表現很細微，典型 wheezing 不一定明顯
- 惡化徵象：**發紺**、胸廓氣體活動減少、使用輔助肌、躁動、無法說話、三腳凳坐姿、冒冷汗、pulsus paradoxus

### 診斷性檢查
- Spirometry：obstructive disease → **FEV1/FVC <70%**

### 急性發作嚴重度（以下需住院）
1. **Position**：sit hunched forward（使用輔助呼吸肌）
2. **Speech**：not able to talk
3. **RR >30**，缺氧無改善
4. **HR >120**（小孩 >125），且有低血壓、心律不整
5. **SpO2 <90%**，有 cyanosis
6. **Auscultation：silent chest** — 氣道整個縮起來，沒有氣體流通（比大聲的 wheeze 更嚴重）
7. **PEF <33%**（預測值或 personal best），或完全呼不出氣、無法測
