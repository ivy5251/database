## Key Points
### 小兒 acute abdomen 三大常見疾病
1. **Acute appendicitis**
2. **Intussusception 腸套疊**
3. **Malrotation with volvulus**

### ⭐ 嚴重的痛
- 整夜睡不著
- 彎著腰三個小時

### Intussusception 腸套疊
- 好發：ileocolic、ileoileocolic
- **典型症狀**
  1. 陣發性哭鬧
  2. 嘔吐
  3. **血便** 👉 PE 時要脫下褲子檢查！
  4. 活動力下降
- 超音波：**target sign**
- Heptabase 補充
  - 小兒三大腹部急症！定義：遠端把近端套住
  - 位置：ileocolic、ileal、colocolic；好發：**ileocolic（最常見）**、ileoileocolic
  - PE：**經常找不到 leading point！！**
  - 顯影劑灌腸：coiled spring sign

### Malrotation
- Malrotation 本身不是急症，**造成的 volvulus 才是急症**
- 叫 **midgut volvulus**（SMA 供應的範圍）
- Volvulus 的超音波：**whirl sign**（腸套疊是 target sign）（Heptabase）

### GI tract X 光 sign（Heptabase）
1. Single bubble：stomach atresia
2. Double bubble：**duodenal** atresia（因為有幽門）⇒ 跟唐氏症有關
3. Triple bubble：jejunal atresia
4. Single bubble with distal gas：midgut volvulus → 懷疑的話趕快做鋇劑的檢查 → **緊急開刀！**
5. Double bubble with distal gas：duodenal web

### 小兒 appendicitis
- Peri-umbilical pain → 發燒、嘔吐
- 為什麼從肚臍轉到右下腹？一開始是 referred pain（肚臍周圍），後來腹膜發炎 → 右下腹痛
- 跳的時候 psoas 用力 → 很痛
- 小孩不太能做 rebound，看 **muscle guarding**

## Management
- Intussusception 治療（Heptabase）：徒手復位 → 鋇劑、氣體灌腸（80–90% 成功機率）→ 手術
- Perforated appendicitis 需要術前治療
- Simple appendectomy 住院約 3 天；perforated 住到一週
- 出院條件：沒有發燒、食量恢復到平常的 1/2
