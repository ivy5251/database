# Facial Bone Fractures

> Source: Notion「顏面骨骨折facial bone fracture」（整形外科）

## Key Points
### 手術適應症
> 記法：臉部最重要的三部分：**眼睛 → 嘴巴 → 外觀**
1. **Diplopia**、**enophthalmos**、眼球活動受限
2. **Malocclusion**、**trismus**
3. Paresthesia
4. Contour depression（≥1 cm）
5. 鼻骨歪斜或凹陷

### Le Fort fracture classification
- 低 → 中 → 高（I、II、III）
- 參考：[Radiopaedia — Le Fort fracture classification](https://radiopaedia.org/articles/le-fort-fracture-classification)
