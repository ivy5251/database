## Key Points
### 手術傷口分級
| 分級 | 種類 | 定義 |
|---|---|---|
| Class 1 | Clean | 無發炎、非外傷、未進入呼吸/消化/泌尿生殖道 |
| Class 2 | Clean-contaminated | **進入呼吸/消化/泌尿生殖道但無特殊感染** |
| Class 3 | Contaminated | 開放性、**新的**外傷傷口 |
| Class 4 | Dirty/infected | 舊的、有壞死組織的外傷傷口、內臟穿孔、感染化膿 |

### 重建階梯
1. Secondary intention
2. Primary intention
3. Skin graft
4. Flap
- 新版：skin graft 之前加上 **NPWT**（負壓傷口治療：敷料連接負壓機，把組織滲液抽到滲液罐）
- **Flap**：保有自身血液循環的組織轉移
  - 用在缺乏血流的傷口（韌帶、關節、骨頭）或缺損太大 skin graft 不夠時
  - 分類：local、distant、free flap（連同血管一起取下）

### 急性 vs 慢性傷口
- 慢性傷口要考慮感染、有膿 → 留檢體

## Management
### 傷口換藥（OSCE）

1. **確認身份**、自我介紹
2. **評估傷口**：洗手、戴口罩、穿隔離衣、戴手套；看大小、外觀是否平整、異物或出血、是否污染
3. **清潔**：用 **normal saline**（不需要用優碘）倒入換藥碗；**由中心往外同心圓**清潔（棉枝或空針沖洗）；無菌鑷夾出異物
4. **消毒**：戴無菌手套；小傷口用洞巾、大傷口用無菌布單；**Aq-BI 棉枝 → N/S 棉枝**
5. **處置**
   - 出血：評估是否血管出血 → 壓迫、縫合、電燒
   - 壞死：清創（無菌剪刀修剪）
   - 無污染 → 縫合；有污染 → 濕敷（N/S : Aq-BI = 20:1 或 10:1），蓋紗布、透明膠帶固定
6. **衛教**：教病人自行換藥、觀察傷口、避免碰生水；給止痛藥、抗菌劑、抗生素（提醒按時吃）；定期回診

## Medications
- **破傷風 tetanus toxoid**
  - 容易長厭氧菌的污染傷口：割傷等深度傷口、很髒的擦傷
  - **15 歲以上且 5 年沒打**要打
